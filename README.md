# 🏫 School Management System

A Python-based School Management System developed using **Object-Oriented Programming (OOP)**. The project aims to simplify the management of students, teachers, and school-related records through a structured, menu-driven application.

## 🚀 Features

- **Student Management:** Add, store, and manage student information.
- **Teacher Management:** Maintain teacher details and records.
- **Person Management:** Use a common parent class to manage shared attributes of students and teachers.
- **Record Management:** Organise and retrieve school-related information.
- **Data Persistence:** Store records locally using JSON files.
- **Object-Oriented Design:** Use classes and objects to keep the application organised and maintainable.

## 🛠️ Technologies Used

- **Python 3** – Core programming language.
- **OOP** – Application architecture.
- **JSON** – Data storage.
- **File Handling** – Reading and writing persistent records.
